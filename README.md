# Bibirble (Web Version)

Bibirble is a Wordle-like game where you guess a Bible verse. This is the original web version of the game. There is a C++ version in development: [Bibirble (C++ Version)](https://github.com/mykzeman/bibirble). This web build is also playable on itch.io: [Bibirble (Web Version) on Itch.io](https://mykzeman.itch.io/bibirble).

## Quick Start

- Open `index.html` in a browser.
- Or serve the folder locally for a better experience:

```bash
# using Node (http-server)
npx http-server -c-1

# or using Python 3
python -m http.server 8000
```

## Install as a Mobile App

Bibirble is a Progressive Web App (PWA). When it's served over HTTPS (or `localhost`):

- **Android (Chrome):** open the site, tap the menu, then **Install app** / **Add to Home screen**.
- **iPhone/iPad (Safari):** tap **Share**, then **Add to Home Screen**.

It opens full screen with its own icon and keeps working offline after the first load. When you ship changes, bump `CACHE` in `sw.js`.

## Project Structure

- `index.html` — main entry page
- `manifest.webmanifest` — app name, icons and colors for installing
- `sw.js` — service worker for offline play
- `fonts/` — Google Material Symbols icon font (only the icons the app uses, so it works offline)
- `icons/` — app icons
- `styles/` — CSS (styles.css)
- `scripts/` — JavaScript files and data
	- `answer.js`
	- `bible_sections.json` — World English Bible verses (the default)
	- `bibles/` — the other 31 Bible versions, gzipped (`<id>.json.gz`); all built by bibirble's `tools/sort.py`
	- `books.js` — book order, tidy book names, areas and authors
	- `christmas.js` — the Christmas verses used all December
	- `data.js`
	- `game.js`
	- `keyboard.js`
	- `submit.js`
	- `useful.js` — the "Useful verses only" pool
	- `versions.js` — remembers the Bible version you pick in Settings
	- `version_list.js` — the Bible versions (generated by bibirble's `tools/sort.py`)
- `LICENSE` — project license
- `README.md` — this file

## How to Play

Color meanings (applies to both the book and the numeric digits):

- **Grey** — the book is NOT correct or the digit is NOT in the verse.
- **Yellow** — the book is NOT correct but is in the same area (see areas below; in hard mode, the same author), or the digit is in the verse but NOT in the right place.
- **Green** — the book is CORRECT or the digit is CORRECT and in the right place.

**Bible versions:** pick from 32 public-domain Bibles in Settings, like the World English Bible, King James Version, Douay-Rheims, Young's Literal Translation and the Septuagint. Only the picked version downloads. Bibles with the Deuterocanon/Apocrypha sort those books into Poetry & Wisdom (Wisdom, Sirach...), Small Stories (Tobit, Judith, Greek Esther), History (1 Esdras) and two new areas: **Prophet Alternatives** (Baruch, Letter of Jeremiah, Greek Daniel, Song of the Three, Susanna, Bel and the Dragon, 2 Esdras) and **Maccabees** (1-4 Maccabees). Some Bibles number most Psalms one lower (Psalm 23 is their Psalm 22). The number keys light up green, yellow or gray as you find each digit.

**Christmas month:** all through December the app gets a festive look, every Daily is a Christmas verse (Christmas Day is always Luke 2:11), and Random games use Christmas verses too while the "Christmas verses" switch in Settings is on.

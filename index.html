Game Overview

Guess the verse by selecting the correct book and entering the chapter:verse digits. Green means exact match, yellow means correct digit in the wrong place, gray means not in the answer.

Daily challenges refresh at UTC midnight. Random games are replayable by seed. Hard mode only accepts valid verses, forces clues to be respected, and a yellow book means the same testament instead of the same area. Turn on "Useful verses only" in Settings to skip genealogies and lists and play only well-known verses.

How to play: Choose a book, then enter the four chapter/verse digits based on the clue.
Seed hint: Use the Settings screen to set or randomize a seed for replayable games.

💪 Welcome to Hard Mode!

  • Only real Bible verses can be guessed.
  • Keep green digits in place and reuse yellow digits.
  • Keep a green book. A yellow book means the answer is in the same testament (Old or New), not the same area.
  • No back button or book areas list. Book hints still work if you turn them on.
